# Supabase Setup for Agatha Living Website

This site stores form submissions in Supabase using the `/api/leads` endpoint.

## 1. Create a Supabase project

1. Go to https://app.supabase.com.
2. Sign in or create an account.
3. Create a new project.
4. Note the `API URL` and `anon key`.
5. Open `Project Settings` → `API` and find the `Service Role` key.

## 2. Set environment variables

Create a `.env.local` file at the project root with:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

> Do not commit `.env.local` to source control.

## 3. Create the `leads` table

Run this SQL in Supabase SQL editor or use the table builder.

```sql
create table leads (
  id bigint generated by default as identity primary key,
  first_name text not null,
  last_name text,
  email text not null,
  phone text,
  enquiry_type text,
  source_page text,
  message text,
  marketing_consent boolean,
  property text,
  check_in text,
  check_out text,
  guests text,
  nights text,
  total text,
  status text default 'new',
  created_at timestamptz default now()
);
```

## 4. Create the `payments` table

Run this SQL in Supabase SQL editor or use the table builder.

```sql
create table payments (
  id bigint generated by default as identity primary key,
  stripe_intent_id text not null,
  property text,
  check_in text,
  check_out text,
  guests text,
  nights text,
  amount bigint,
  status text,
  created_at timestamptz default now()
);
```

## 5. Install dependencies

```bash
npm install
```

## 5. Run the site locally

```bash
npm run dev
```

## 6. Verify lead capture

Submit the contact form, priority guest list form, or booking enquiry.
Then verify the record appears in the `leads` table.

## Notes

- `/api/leads` uses the service role key on the server only.
- The site does not expose the service role key in browser code.
- If you want email notifications from new leads, you can add a Supabase function or webhook later.
